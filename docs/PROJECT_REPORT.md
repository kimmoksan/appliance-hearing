## 유지 규칙

- 프로젝트명은 가칭. 화면의 BEFORE를 최종 이름이라고 쓰지 않는다.
- 제출자 실명은 추정하지 않는다. 대화 호칭(‘피터’)을 제출 이름으로 쓰지 않는다.
- 기술스택은 실제 채택·구현한 것만 최종 보고. DB가 없는데 SQLite를 넣거나 Gemini를 다른 API로 바꿔 쓰지 않는다.
- 저장소는 현재 **private**. 제출처가 접근해야 하면 공개 전환 또는 접근 권한 부여가 필요하다(사용자 결정).
- 실제 AI 연동 / 예시 데이터 / 사용자 테스트 / 배포 검증을 각각 구분한다. 미완료를 완료처럼 쓰지 않는다.
