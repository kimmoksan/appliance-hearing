# 제품 카탈로그 v0

- 데이터: [catalog_v0.json](catalog_v0.json) — 24개 제품, 확인일 2026-10-30.
- 범위: 삼성·LG × 로봇청소기·식기세척기·건조기·공기청정기 × 각 3개.
- 사양은 제조사 공식 상세 표, 판매 여부는 가격·구매하기가 표시된 실제 판매 페이지로 따로 확인했다.
- [검증 근거](VERIFICATION.md): 24개 공식/판매 URL, 선정 이유, 항목별 사양 대응, 미확인·충돌·확인 한계.
- [개발 인계](DEVELOPMENT_HANDOFF.md): 읽은 문서, 실제 코드 상태, 다음 개발 순서와 검증 결과.
- HY856RSAAP는 본체 HY856RSAA와 액세서리를 묶은 실제 판매 코드다. 단품과 중복 집계하지 않는다.
- RG20WN·RG18WNST의 의미가 혼재된 기존 필드 2개는 키를 유지하고 값은 문자열 `미확인`으로 남겼다.
- JSON의 최상위 구조와 기존 22개 제품의 p 키는 보존했다. 판매 링크·검증 설명은 별도 문서에만 기록했다.
- 대표 모델은 용량·설치·라인 범위를 위한 선정이며, 시장 판매량 순위를 뜻하지 않는다. 실시간 가격·재고 보장은 없다.
- 카탈로그의 앱 연결은 아직 미구현이다. 문서를 읽는 것과 앱이 데이터를 사용하는 것을 구분한다.

사용자의 후속 지시(2026-10-30)에 따라 카탈로그·검증·인계 문서를 별도 문서/데이터 커밋으로 반영한다. 후속 기능 개발에서는 카탈로그를 읽기만 한다.
