# MoSCoW — 가전 구매 청문회

기준: 2026-10-30 인계 문서. 이 문서는 세 종류를 **구분해서** 기록한다.

1. **확정** — 사용자가 명시적으로 정했거나 보류에 동의한 것
2. **현재 선택** — 사용자 원본 230개 분류 + 명시 수정 + 승인된 W 변경 (부록)
3. **검토 제안** — 앞선 리뷰의 승격·조정 권장안. 2026-10-30에 사용자가 항목별로 결정해 부록에 반영함 (§2)

## 1. 확정 사항

| 주제 | 확정 방향 |
|---|---|
| 제품군 | 로봇청소기·식기세척기·건조기·공기청정기 4개 기준 |
| 핵심 입력 | 제품 정보 + 구매 이유 한 줄. 긴 필수 설문 없음 |
| 도트 구성 | 고정 배경 + 소수 소품 ON/OFF + 제품 단순 상태 효과 + 설명 카드 |
| 인물 동작 | 공통 보행·정리·적재 엔진 필수 아님. 인물은 정적이어도 됨 |
| F10 | 맞춤 장면 구성 실패 시 제품군 기본 사용 장면 재생 + ‘기본 사용 장면’ 표시 |
| F07 (설명·애니메이션 일치) | 범위 정의는 ‘표현한 조건과 설명이 모순되지 않게, 정밀 재현 아님’. 등급은 **W 유지**(10/30 결정) |
| J07 | 외부 자료 속 지시가 AI 진행 규칙을 바꾸지 못하게 — **M** |
| N02 모바일 | 같은 웹에 Grid/Flex + 미디어 쿼리 반응형 — **M** |
| N06 | 스크린리더 전반 지원은 **C**. 기본 label·키보드·초점은 유지 |
| W01~W10 | 전부 이번 **W** (비교·리뷰 분석 포함) |

### 1.1 확정된 보류(W) 묶음

- 이미지/PDF 업로드와 그 처리
- 현재 탭 상태를 넘는 영구 기록·회원·동기화·공유·결과 저장 및 권한/만료
- 관리자 웹 도구, 자동 장애 알림, 서버 데이터 백업
- 백업 모델, 개인화 결과 캐시, 부분 JSON/스트리밍 표시
- 후속 피드백 수집, 외부 분석 도구, 변경/점검 공지
- 확장 W01~W10 (비교·대체 제품·가격 추적·리뷰 분석·제휴·AR·꾸미기·음성·다국어·구독결제)
- 직접 게임 조작(캐릭터 이동·가전 버튼·자유 배치), 실제 집 크기/구조/축척 재현, 성능 물리 시뮬레이션

제품 자료 수정·근거 검토 자체는 남는다. 초기엔 검토한 설정 파일 + 수동 점검으로 하고 관리자 화면은 만들지 않는다.
